# The Reclaimers (working title)

A player-hosted online co-op scavenging game for 1-4 friends, built by one founder and a
team of coding agents. Twelve years after a sickness emptied the city, inspectors lift the
ring fence one sector a week. You build a settlement at the edge of the overgrown city,
go in with a friend for what the city left behind, and get back through the gates by dusk.

Steam first, premium price. Rust authoritative server and simulation; C# client, with the
engine (Godot 4.7 or Unity 6) chosen by a bake-off.
